# 晶島物語：TP查核學習島

完整可編輯靜態網站專案。所有企業、人物與交易案例均為虛構；案件以查核證據、功能風險分析與方法選擇展開。含島景動畫、居民訪談、分支案件、融資比較、結案報告及BAPA談判。

## 開始使用

1. 安裝 Node.js 18以上版本。
2. 解壓縮後，在本資料夾開啟終端機。
3. 執行 `npm start`，開啟 http://127.0.0.1:4173 。不需要安裝套件。
4. 執行 `npm test` 驗證案例、計算與對話流程。

重新產生ZIP可執行 `npm run package`（另需Python 3）。ZIP不包含自身、網站帳戶識別或登入憑證。

## 修改位置

- `dist/index.html`：主島入口；`island-stage.css/js`：全螢幕島景及另開工作頁。
- `dist/world.js`、`island-3d.js`：居民世界與立體場景（依檔內模組分工）。
- `dist/dialogue-voices.js`、`resident-dialogue.js`：個人化居民語氣與分支。
- `dist/casebook.js`、`rpg.js`：自由選擇的案件與訪談。
- `dist/bapa-data.js`、`bapa-editorial.js`、`bapa-logic.js`：談判情境、逐輪攻防與計算。
- `dist/mist-island/index.html`：甲、A、B、C查核、融資、回銷及未回銷計算。
- `tests/`：Node內建測試；`scripts/`：本機啟動及打包。

## 操作及資料

主畫面以島景為主，案件、居民與BAPA工作頁由上方另開。進度保存在同一瀏覽器的localStorage，跨裝置不會自動同步。文字對話採多場景腳本與關鍵字判讀，沒有外接生成式AI服務，亦不需要API金鑰。臺灣甲公司實際新臺幣2%借款與美元信評比較樣本分開呈現；不將模擬數據視為市場報價。

BB原液案主線與臺灣另有獨特秘密配方的平行支線具不同事實。低直接材料成本不代表技術沒有價值，原料價格可以包含無形資產對價；是否採TNMM或利潤分割，須取決於實際FAR與可比資料可靠性，不能只因利潤高就調整。教學結論不替代具體個案的法令適用。

可直接將dist資料夾部署於靜態網頁主機。OECD及我國法規連結需要網路；場景、腳本及模擬計算可在本機運作。音效、下載與多視窗可能依瀏覽器設定而異。
